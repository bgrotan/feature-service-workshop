# Denne mappen inneholder freemarker-templates (maler) for HTML-rendring gjennom OGC API Features

Malene hører hjemme under:
```
<GEOSERVER_DATA_DIR>/templates/ogc/features/v1
<GEOSERVER_DATA_DIR>/workspace/workspace/ogc/features/v1
<GEOSERVER_DATA_DIR>/workspace/workspace/datastore/ogc/features/v1
<GEOSERVER_DATA_DIR>/workspace/workspace/datastore/featuretype/ogc/features/v1
```

For workshopen vil da `<GEOSERVER_DATA_DIR>` typisk være `geoserver_data`, alt etter hva man har definert i `docker-compose.yml`

For mer beskrivelse - se [Geoserver dokumentasjon](https://docs.geoserver.org/main/en/user/services/features/templates.html)

Malene tilhører [øving 4.3](../../ovinger/oving-4.md) - og er laget for Geoserver 2.28.0
